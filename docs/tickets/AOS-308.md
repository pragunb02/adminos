## Description
- Every page currently fetches data by calling a function that sets state inside `useEffect` (flagged by React 19's `react-hooks/set-state-in-effect`; 8 places across 7 pages).
- Introduce one data-fetching layer (loading, error, cache, refetch, pagination) used by all pages.
- Then set the lint rule back to **error**.

## Why
- Cascading renders and duplicated loading/error code in every page.
- One seam for auth refresh (AOS-109) and API errors.
- This is a prerequisite for the Milestone 3 console pages.

## Design (to be approved before coding)
- **Options:**
  1. TanStack Query
  2. SWR
  3. A custom `useApi` hook
- **Leaning:** TanStack Query (caching, pagination, retries, devtools; widely used).

## Acceptance criteria
- [x] No `react-hooks/set-state-in-effect` warnings; rule back to `error`
- [x] All pages use the layer; lint/typecheck/build green
