## Description
Update all Go modules to latest, set the Go version to 1.27, and fix the Dockerfile: it uses golang:1.21 but `go.mod` requires 1.25, so the build is broken.

## Approach
Build and test inside the official `golang:1.27` image, so no local Go install is needed (AOS-114 becomes optional).

## Acceptance criteria
- [x] No direct-dependency updates left: Go 1.25 → **1.27**, pgx 5.9.1 → **5.11.0**, go-redis 9.18.0 → **9.23.0**; asynq 0.26.0 and uuid 1.6.0 were already latest; indirects updated by `go get -u` + `tidy`
- [x] `go build`, `go vet` and `go test` green before **and** after (the workers' first-ever verified build in this project)
- [x] Worker image builds:
  - golang:1.27-alpine builder, alpine:3.24 runtime
  - runs as non-root `app` (uid 100)
  - `-trimpath -ldflags=-s -w`
  - `.dockerignore` added
