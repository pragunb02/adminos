## User story
**As** the owner, **I want** to set goals like "cut quick commerce 30%" and see my savings rate climb, with what the saved money could become, **so that** saving feels like progress towards wealth.

## Acceptance criteria
- [ ] The Home headline shows this month's savings rate and its trend
- [ ] A goal shows progress and a streak
- [ ] Every projection shows its assumptions (return, years)
