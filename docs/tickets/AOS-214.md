## Description
The balance-alert drop rule `^(?!.*\b(debited|credited|spent|sent|paid|received)\b).*\b(available balance|avl bal)\b`
did not know `Dr`/`Cr`/`Dr.`/`Cr.`, "debit", "credit", "withdrawn", "txn". So "Your A/c XX5678 is Dr. with Rs.1,200.00 …
Avl Bal Rs.8,800.00" and "Rs 2,000 withdrawn at ATM … Avl Bal …" were silently dropped.

## Why
Lost transactions: many banks append the balance to every debit/credit alert (AOS-S2.5).

## Scope
- **In:** the balance-alert rule in `SmsParserRegistry` (SMS and WhatsApp).
- **Out:** other drop rules.

## Acceptance criteria
- [x] Dr/Cr, Dr./Cr., debit, credit, withdrawn, paid, spent, txn alerts that also show the balance are kept (HDFC, SBI, ICICI, Axis, Kotak, generic)
- [x] Pure balance alerts are still dropped, including a balance marked `Cr`/`Dr` ("Avl Bal … Rs 8,800.00 Cr") and card balance/limit alerts
- [x] The balance figure is never the amount

## Design
- **Options considered:** 1) add words to the negative lookahead (a second, drifting copy of the parser's vocabulary;
  "Avl Bal Rs 8,800 Cr" would then look like a transaction); 2) one shared vocabulary (`SmsSignals`) used by the rule
  and the parsers, applied after balance and limit figures are blanked out.
- **Decision:** option 2. A message is a balance alert when it mentions the balance and, balances aside, has no
  transaction signal (`SmsSignals.mentionsTransaction`). "Credit card", "debit card" and "credit limit" name products,
  not movements. **Patterns:** Specification; drop rules are now `(predicate, reason)` pairs.
- **Impact:** domain only. No schema, route or contract change.

## Security
- **Exposes:** nothing new. **Abuse:** a forged "balance" SMS can now become a transaction only if it carries a
  transaction signal and an amount, exactly like any other bank SMS (senders are TRAI business headers; promotional
  headers are dropped first). Regexes are bounded (`{0,60}?`), tested on 2,000-character hostile text.
- Reasons never quote the text (D-33). Fixtures are synthetic.

## Verification
- Before: SBI Dr., Kotak Cr., ICICI Dr., Axis "Debit", SBI "withdrawn", Kotak "Credit of" each `Ignored(balance alert)`.
  After: `DEBIT 1200.00`, `CREDIT 3000.00`, `DEBIT 249.00`, `DEBIT 450.00`, `DEBIT 2000.00`, `CREDIT 10000.00`.
  "Avl Bal in your SBI A/c XX5678 is Rs 8,800.00 Cr" stays `Ignored(balance alert)`.
- Gates as in AOS-213.

## Resolution
The balance-alert rule uses the shared `SmsSignals` vocabulary on the text with balance figures removed. The Axis UPI
narration pattern also stops at "Avl"/"Avail", so the payee isn't "ZOMATO Avl Bal …". Merge pending reviews.
