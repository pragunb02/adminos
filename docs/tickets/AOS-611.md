## Problem (found by AOS-312 tests)
- Totals are added as `Double`:
  - `TransactionRoutes.kt:79`: ₹100.10 + ₹200.20 = 300.29999999999995;
  - `SubscriptionRoutes.kt:70`: 948.6700000000001.
- `TransactionResponse.amount` is a `Double`, with no `nature` field, so the feed can't tell refunds or transfers apart (PROGRESS #8).

## Fix
- `BigDecimal` sums.
- Every money field in these responses becomes an exact 2-decimal string.
- `TransactionResponse` gains `nature`.
- The web types and pages are updated, and money is never added up in the browser.

## Regression tests (exist today as `@Disabled("BUG AOS-312 …")`; the fix enables them)
- `FinancialTransactionRoutesCoverageTest` › exact totals
- `FinancialSubscriptionRoutesCoverageTest` › exact totals
- New: contract test for string amounts + `nature`; web unit tests updated.

## Impact
API contract change for amounts (number → string), in the same PR as the web update.
