## Description
Found by AOS-623 (ZAP 10038): the proxy matcher excluded `favicon.ico`, but the app has no favicon, so `/favicon.ico` rendered Next.js's 404 HTML page without our nonce CSP.

## Acceptance criteria
- [x] The matcher excludes only `_next/static` and `_next/image`; every page response (including 404s) goes through the proxy and gets the CSP.
- [x] Test: `/favicon.ico` and an unknown path match the proxy; static chunks don't (`proxy.test.ts`).

## Security
Low: no attacker-controlled content was on that page, but every HTML response should carry the policy (D-94).

Done in `apps/web/src/proxy.ts`, with a test in `proxy.test.ts`.
