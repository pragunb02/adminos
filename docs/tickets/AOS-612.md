## Problem (found by AOS-312 tests)
- `BillRoutes.kt:40` pages by due date alone with `dueDate > cursor`, so bills on the same date are skipped.
- `BillTrackingService.kt:24`: a refund can mark a bill paid.
- `BillTrackingService.kt:139`: a ₹0.00 bill never matches.
- `DashboardRoutes`: the greeting and the "days to due" count use Asia/Kolkata or the server clock, not the user's timezone (AOS-120).

## Fix
- Cursor = (dueDate, id) via `CursorCodec`.
- Match only debits/spend.
- Compare with `signum()`.
- Use `call.userZone` for the greeting and day counts.
