## Description
When the period is a month (the Home default), the console adds:
- **Running total:** a cumulative line, this month (solid, accent) against the previous month (dashed, grey), on day of month 1…31, with today marked.
- **Day by day:** a column for every day of the month.

Each has a one-sentence text alternative and a table (D-49). Totals equal the headline (D-46).

## Acceptance criteria
- [x] The cumulative line's last value equals the month's spent; last month runs to its last day.
- [x] Refund-only days lower the running total (D-46), so it isn't clipped.
- [x] The sentence describes it: "Spent ₹48,250 by 16 Oct; ₹4,200 more than by 16 Sept."
- [x] Week and day periods keep the "This week" bars and don't show the month sections.
- [x] Unit + Playwright tests; axe clean.
