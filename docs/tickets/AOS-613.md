## Problem (found by AOS-312 tests)
- `ReminderEngine.kt:49-50`: duplicate reminder days (e.g. `[3,3]`, allowed by PATCH) send twice.
- `DropOffNudgeService.kt:57/64`: the cap counts records per channel, so the day-1 nudge uses up the whole cap of 3.
- `ConnectionRoutes.kt:55`: a failed Google code exchange → 500 instead of OAUTH_FAILED.
- `ConnectionRoutes.kt:63-67`: Gmail is "connected" without a code, under the placeholder `user@gmail.com`.
- `ConnectionService.kt:33-48`: reconnect after disconnect inserts a duplicate row (violates `uq_conn_source` on Postgres).
- The Gmail cron's `skipped` counter is never incremented.

## Fix
- De-duplicate reminder days on read and on PATCH.
- Count nudge *sends* (distinct by day), not channel records.
- Map the exchange failure to 400 CONN_002.
- Require a code + client, else 400.
- Reactivate the existing row on reconnect.
- Count skipped connections.
