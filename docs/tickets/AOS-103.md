## Description
Add the `stringtype=unspecified` data-source property in DatabaseFactory (and the test).

## Why
Exposed maps enum/JSONB/INET as varchar; without it Postgres rejects the inserts.

## Acceptance criteria
- [x] Inserts into enum/JSONB/INET columns succeed (the 4 previously failing `ExposedUserRepositoryIntegrationTest` cases now pass)

## Implementation plan
1. Add `addDataSourceProperty`

- The integration test builds its connection pool through the production builder instead of its own `Database.connect(url…)`, so it now covers production settings.
- `./gradlew test integrationTest`: unit tests green; integration **8/8** (was 4/8).
