## Description
Upgrade the Kotlin API to the latest stable dependencies, following the AOS-S1.0 design (one step at a time, tests green after each step).

## Why
The AOS-009 audit found most libraries 1+ majors behind (D-28).

## Acceptance criteria
- [x] All dependencies at latest stable (`./gradlew dependencyUpdates` shows only pre-releases newer)
- [x] Versions in `gradle/libs.versions.toml`
- [x] JDK 25 toolchain (bytecode major 69 verified)
- [x] `./gradlew test` green (130/130)
- [x] `./gradlew integrationTest` runs (8 tests; it ran 0 before). 4/8 pass. The 4 user-repository failures are the existing enum-as-varchar issue → **AOS-103**, not upgrade regressions.

## Design
See AOS-S1.0. Deviation: Gradle 9 can't load the Ktor 2 plugin, so Gradle, Kotlin, Ktor, Koin and the JDK moved in one step.
