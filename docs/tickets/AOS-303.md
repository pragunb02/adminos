## Description
Frame **M/Home** of `docs/design/console.md`, top to bottom:
1. Period switcher (Day / Week / Month, in the URL).
2. **Hero:** spent so far, plus the change against the **same days** of the previous period, in words and with an arrow; received and net below it.
3. **Review banner** when suggestions wait.
4. **This week**, day by day (bar chart, with a table alternative).
5. **Where it went:** the top 5 categories as bars, with share.
6. **Top merchants:** the top 5.
7. **Latest** 5 transactions.
8. **Coming up:** bills due within 7 days.
9. **Needs attention:** open anomalies, from the old dashboard.

## Acceptance criteria
- [x] Every number comes from the analytics API, exactly (D-30 strings); totals follow D-46.
- [x] The comparison is "by the same day" of the previous period (e.g. Oct 1–16 vs Sep 1–16).
- [x] The period is in the URL: ◀ ▶ and Day/Week/Month push history; back/forward/refresh restore it; an invalid URL shows a notice and this month.
- [x] States: loading skeleton, new-user empty state (import / SMS / cash), an empty period, an error card with retry per section (other sections still show).
- [x] Charts: role=img + a one-sentence label + "View as table".
- [x] Unit + Playwright tests (incl. a period back/forward chain, mobile + desktop) and axe clean; coverage gates hold.
