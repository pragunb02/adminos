## Description
`/spending?view=trends` (docs/design/console.md, M/Spending "Trends"):
- **Last 12 months:** spent and received per month, as **paired bars** (the default) or **lines**. The choice is in the URL (`chart=bars|lines`). Months end with the period's month.
- **Last 12 weeks:** spent per week (Monday weeks) as a line.
- Each chart has a one-sentence text alternative and a "View as table".
- Comparing months is like-for-like: the current month is labelled "so far".

## Acceptance criteria
- [x] Ranges: 12 months = the 1st of the month 11 months before → the period end; 12 weeks = the Monday 11 weeks before → the period end.
- [x] The view and chart type are in the URL; back/forward/refresh restore them.
- [x] Sentences name the highest month and the latest values; tables show exact amounts.
- [x] Unit + Playwright tests; axe clean.
