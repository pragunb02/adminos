## Design
- **Context:**
  - The deterministic engine is strong: parsers fail closed and the rules are precise.
  - AOS-511 measured categorisation (82.6% accuracy, 69.4% coverage; misses are "Other").
  - AOS-512 adds an LLM fallback for "Other".
  - A legacy Go Claude client exists but appears unused.
- **Options considered:**
  1. One report plus an epic with grouped stories (chosen).
  2. One ticket per idea with no shared rules. Rejected: each feature would re-decide privacy and validation.
- **Decision:** the report plus D-67 ground rules. **Patterns:** port and adapters for providers; Specification-style validators for grounding and number checks.
- **Extensibility:** a new AI feature is an `AiFeature` entry, a redactor, a validator, an eval set and a baseline.
- **Impact:** docs only.
