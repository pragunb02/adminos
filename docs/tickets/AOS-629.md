## Description
`ConnectionService(…, tokenEncryptor: TokenEncryptor? = null, …)` accepted no encryptor. In that case it logged a
warning and stored OAuth tokens as given (AUD-25, [AUDIT-2026-10](../security/AUDIT-2026-10.md)). Production always
passes one, but the plaintext path existed. Now the encryptor is a required, non-null parameter, so the path is gone.

## Why
Fail closed (ENGINEERING §2): a wiring mistake must not silently store Google refresh tokens in plaintext. Low, CVSS 2.0.

## Scope
- **In:** the constructor, `encryptToken`, the removed warning, and the tests that built the service without an encryptor.
- **Out:** `TokenEncryptor` itself, and the worker's cipher (it already refuses to start without the key, D-59).

## Acceptance criteria
- [x] The parameter is non-null with no default. Every constructor takes it, and a `null` (from Java or reflection) fails at construction. Test: `a ConnectionService can't be built without a TokenEncryptor`
- [x] Tokens are always stored in the v2 encrypted format, on reconnect too. Tests: `tokens are never stored as given, on reconnect either (AOS-629)`, `oauth tokens are stored encrypted, not in plaintext`
- [x] The plaintext test is gone. Tests that need a service get a key generated per run (`randomTokenEncryptor()`), never a literal.

## Design
- **Options considered:**
  1. Keep the nullable parameter and throw in `init`. That is a runtime check of something the type system can state.
  2. **Make the parameter non-null with no default** (chosen). A missing encryptor no longer compiles, and Kotlin's parameter null-check covers Java and reflection callers.
- **Impact:** API only. Koin already provides `TokenEncryptor` (`AppModule`, `TestAppModule`). No schema change.

## Security (threat review, ENGINEERING §4a)
- **Exposes:** nothing; it removes a code path.
- **Abuse and what stops it:** a mis-wired service (a test module copied to production, a DI change) that would have stored tokens in plaintext now doesn't compile, or fails at start-up. There is no warning-and-continue path left.
- **Tests that attack it:** reflection with a `null` encryptor, and stored tokens checked for the v2 format. No route or screen.
