## Description
Frame **M/Activity** of `docs/design/console.md`: every transaction, searchable and filterable, grouped by day, editable in place.

## Acceptance criteria
- [x] Search, category, kind (nature) and dates are in the URL. Typing **replaces** the URL (debounced); applying filters **pushes** it. Back/forward/refresh restore them.
- [x] Filters apply together: an inline bar on desktop, a sheet with Apply/Cancel on phones; nothing changes while choosing.
- [x] Active filters show as removable chips.
- [x] A Home/Spending period (`p`/`d`) opens Activity with that date range.
- [x] Grouped by day (Today, Yesterday, weekday, date); signed amounts; kinds in words.
- [x] A row opens a sheet (`?txn=id`), which Back, Escape, Close or the backdrop closes. It changes the category, remembered for the payee by default (D-41), with an **Undo** toast (5 s).
- [x] Paging never skips rows that share a timestamp.

## Resolution
Done.
- **API:**
  - `nature` filter on `GET /transactions` (both repositories, count included; unknown → 400);
  - **paging fixed:** the cursor is (time, id), newest first. It used to be time alone, which skipped statement rows sharing a timestamp. Old time-only cursors still work.
- **Web:**
  - `app/transactions/page.tsx` rewritten: search, `FilterBar` (desktop bar / mobile sheet), chips, day groups, load more, `TransactionSheet`, `UndoToast`;
  - `FeedRowContent` (valid HTML inside buttons).
- **Found by the tests and fixed:**
  - a deep-linked sheet initialised its category before the row loaded, so Save was enabled with the wrong category;
  - the filter draft didn't reset when the URL changed.
- **Undo** re-applies the previous category with the same "remember" choice: the payee's rule goes back to the old category and past rows are re-labelled back. Rows the rule had already set to the new category earlier aren't distinguished; noted for later.
- **Tests:**
  - API: same-time paging + nature in-memory and on Postgres. Unit 1,059 / integration 88; gate passes.
  - Web: Activity 13 unit tests; web 274, 98.95% lines / 96.04% branches.
  - Playwright `activity.spec.ts`: filter apply/chips/back/refresh/forward, search replace (Back skips letters), sheet with Back/Forward, save → Undo, Escape, period → dates, load more; on 3 browsers. Total 202 passing + 4 deliberate skips (keyboard on phones); axe on the sheet.
