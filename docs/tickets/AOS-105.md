## Description
Round-trip (save → find → update → find) integration tests on real Postgres for all 15 Exposed repositories. They also save every value of every enum used, to catch Kotlin/SQL drift.

## Design
- **Shared database:** one Testcontainers Postgres for the whole suite (`PostgresTestDatabase`), migrated once with real Flyway through the production pool builder.
- **Isolation:** every test creates its own user (`newUser()`), so tests are independent.
- **Layout:** one test class per domain (identity, ingestion, financial, agent, notifications, audit).

## Acceptance criteria
- [x] All 15 repositories covered: 6 domain test classes plus the user test; integration **31/31**
- [x] Every enum value used by a repository round-trips (no remaining Kotlin/SQL drift)
- [x] Bugs found and fixed, each with regression tests (below)

## Bugs found
1. **Metadata could never be saved (production bug).**
   - Every `Map<String, Any?>` JSONB column crashed on save with `Serializer for class 'kotlin.Any' is not found`, in 6 repositories: transactions, accounts, subscriptions, bills, briefing content and insight payloads.
   - Decoding was also wrong: it returned `JsonPrimitive` wrappers, not plain values.
   - **Fix:** a single `JsonColumns` mapper in the persistence layer.
     - It fails loudly on unsupported types.
     - It writes **exact decimals**: `JsonPrimitive(BigDecimal)` went through Double and lost scale and precision.
     - Unit tests in `JsonColumnsTest`.
2. **9 tests had never run.**
   - JUnit silently skips `@Test` methods that return a value (`= runBlocking { …assertNotNull(x) }`).
   - The skipped tests were in AuthServiceTest (3), ConnectionServiceTest (2), BillTrackingServiceTest, IngestionServiceTest, the user repository test and my new session test.
   - **Fix:** all 67 test bodies use `runBlocking<Unit>`.
   - **Guard:** `TestConventionsTest` fails the build if any test method returns non-void. It also asserts that it scanned >100 tests. It was proven with a probe: it fails on an offender and passes without one.
   - All 9 now run and pass.
3. **Stale incremental compile.** Gradle once ran stale Kotlin classes (stack trace pointed at pre-edit lines). A clean build resolved it. If a result contradicts the code, run `./gradlew clean`.

## Resolution
- `PostgresTestDatabase` provides one shared, Flyway-migrated container for the suite, built with the production pool. The user test moved onto it too, so no second global Exposed connection exists.
- Unit **142/142**, integration **31/31**.
- Actual 2h vs ETA 3h.
