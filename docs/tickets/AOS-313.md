## Description
`activity.spec.ts` "a Home period opens Activity with that date range" failed twice on iphone-safari (in the AOS-403 and AOS-406 runs) and passed on repeat. It checked `api.calls` once, right after the filter chip appeared; the chip can render before the feed request is recorded.

## Acceptance criteria
- [x] The test waits for the `/api/v1/transactions` request (`expect.poll`) instead of checking once.
- [x] It passes on repeat on every browser.

## Design
1. **Poll for the request** (chosen): states the intent and is reliable.
2. `page.waitForRequest` before navigating: also works, but couples the test to the request's timing relative to `goto`.

## Verification
`npx playwright test e2e/activity.spec.ts --repeat-each 10`: 160 passed (all three browsers); typecheck and lint pass.
