## Description
Public onboarding and hosting.

## Launch requirements (from earlier work)
- **Edge proxy must own `X-Forwarded-For` (D-32, AOS-108).** Put Caddy, nginx or a cloud LB in front of the web app and have it set `X-Forwarded-For` to the connecting client address. Next passes it through and the API trusts the last hop. Without it, rate limiting and audit IPs are spoofable.
- Cookie `Secure` flag (already on for non-localhost `APP_URL`).
