## Description
Found by AOS-623 (`pentest-probes.sh`): `TRACE /login` on the web app returns `500 Internal Server Error` with a generic body. Next.js throws `'TRACE' HTTP method is unsupported` while building the request, before our proxy runs, so the response has none of our security headers, and each request logs a stack trace.

## Acceptance criteria
- [x] Reproduced: 500, generic `Internal Server Error` body, no request data echoed, no security headers; a stack trace in the web log.
- [x] Impact assessed: no data or internals are disclosed to the caller; the log line is noise an unauthenticated caller can trigger (bounded by reachability: tailnet only, D-97).
- [ ] When the edge (AOS-605) is set up, it allows only GET, HEAD, POST, PUT, PATCH, DELETE and OPTIONS to the web app; re-run the probe.

## Security
Low. It can't be fixed in the app (the error is inside Next.js before any user code). The site is reachable only over the tailnet (D-97), so only the owner's devices can send it.
